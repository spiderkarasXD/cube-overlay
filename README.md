# Cube Overlay

Оверлей в духе Steam для Minecraft (Fabric). Нажимаешь комбинацию кнопок и поверх игры
появляется панель с браузером.

- **Браузер с вкладками** (до 8). Внутри настоящий Chromium через MCEF Modern, так что YouTube, Twitch и Google работают.
  Если закрыть оверлей, вкладки не закрываются, поэтому музыка и видео продолжают играть.
- **Бинд из нескольких кнопок**: по умолчанию `Left Shift + Tab`. Можно записать любую комбинацию
  до 3 кнопок, клавиатуру и мышь можно смешивать (например `Ctrl + колёсико` или `Мышь 4 + Мышь 5`).
- Боковая панель: часы и дата, сервер или мир, время сессии, FPS, координаты, измерение, здоровье.
- Быстрые ссылки внизу, адресная строка (если ввести не адрес, а текст, откроется поиск в Google).
- Горячие клавиши как в браузере: `Ctrl+T` новая вкладка, `Ctrl+W` закрыть вкладку, `Ctrl+L` перейти в адресную строку,
  `Ctrl+Tab` следующая вкладка, `F5` обновить страницу. Вкладку можно закрыть средней кнопкой мыши. `Esc` закрывает оверлей.
- По умолчанию игра не ставится на паузу (как в Steam). Это меняется в настройках (⚙).
- У оверлея свой масштаб, он не зависит от «Масштаба интерфейса» Minecraft. На «Авто» он примерно ×2 на 1080p и ×3 на 1440p,
  в настройках можно выбрать 1×–4×.

## Установка

Положить в `.minecraft/mods` три мода **под свою версию игры**:

| Minecraft | Cube Overlay | MCEF Modern | Fabric API |
|---|---|---|---|
| 1.21.11 | `cube-overlay-1.0.0+mc1.21.11.jar` | `0.3.3+mc1.21.11` | 0.141.3+ |
| 26.1.x | `cube-overlay-1.0.0+mc26.1.2.jar` | `0.3.3+mc26.1` | 0.144.1+ |
| 26.2 | `cube-overlay-1.0.0+mc26.2.jar` | `0.3.3+mc26.2` | 0.152.2+ |
| 26.3 | `cube-overlay-1.0.0+mc26.3.jar` | `0.3.3+mc26.3` | 0.161.0+ |

MCEF Modern: https://modrinth.com/mod/mcef-modern
Fabric API: https://modrinth.com/mod/fabric-api

При первом запуске MCEF один раз скачивает Chromium (~150 МБ) в фоне. Пока идёт загрузка, оверлей показывает прогресс.

## Настройки

Кнопка ⚙ в правом верхнем углу оверлея. Там можно сменить бинд, домашнюю страницу, паузу, размер интерфейса и затемнение.
Всё хранится в `config/cube-overlay.json`, там же можно поменять список быстрых ссылок.

## Сборка

Нужна JDK 25 (Gradle скачивается сам).

```bash
JAVA_HOME=/путь/к/jdk-25 ./build-all.sh
```

Jar-файлы появятся в `dist/`. Как устроен проект:

- `common/` содержит весь код мода, одинаковый для всех версий.
- `versions/<mc>/` содержит отдельную Gradle-сборку под каждую версию и три маленьких класса в `compat/`
  (рисование, переключение экранов, ввод), потому что Mojang между версиями переименовывает GUI API
  (`GuiGraphics` → `GuiGraphicsExtractor`, GLFW → SDL в 26.3 и т.д.).

Самопроверка в dev-клиенте: `./gradlew runClient -Pselftest`. Мод сам откроет оверлей и прокликает кнопки, адресную
строку, вкладки, настройки, клик и ввод (Backspace/Enter) на тестовой странице. В лог пишется `[selftest] PASS/FAIL ...`.

## Публикация

Тексты для страницы мода лежат в `publish/` (описание, changelog, иконка, скриншоты). Сами проекты на Modrinth и
CurseForge создаются вручную на сайтах, потом все 4 jar заливаются одной командой:

```bash
python tools/publish.py           # пробный прогон
python tools/publish.py --upload  # залить
```

Токены и ID проектов берутся из переменных окружения, список есть в начале `tools/publish.py`.
