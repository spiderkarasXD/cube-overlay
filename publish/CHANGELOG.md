## 1.0.2

- The overlay interface follows the game language (English and Russian; other languages fall back to English).

## 1.0.1

- Typing in web pages: Backspace, Enter, arrows, Delete, Home/End and Ctrl+A/C/V/X/Z now work (Windows).
- The browser follows the game language: Google and YouTube open in the language selected in Minecraft.
- Clicking the address bar selects the whole address; clicking anywhere on a text field focuses it.

## 1.0.0

First release.

- Steam-style overlay that opens with a bind of up to 3 buttons (keyboard + mouse, default Left Shift + Tab).
- Chromium browser with tabs (MCEF Modern), address bar with search, hotkeys.
- Side panel: clock, session, FPS, coordinates, dimension, health.
- Quick links dock, settings screen, own UI scale.
- Backspace, Enter, arrows, Delete, Home/End and Ctrl+A/C/V/X/Z work in web page fields (works around the missing scancode in MCEF Modern on Windows).
- Supports Minecraft 1.21.11, 26.1.x, 26.2, 26.3 (Fabric).
